## Решения

### Карточка тайтла

Backdrop — `h-[40vh]` (220–420 px) через `posterUrl(path, 'w780')`, поверх него
шапка с «Назад» и градиент в `bg`. Постер 96 px на телефоне и 112 px на десктопе
заходит на backdrop на 64/80 px. Кнопка «Найти раздачи» закреплена внизу
(`fixed`, `pb-[max(12px,env(safe-area-inset-bottom))]`), контент получает `pb-32`.

Мета-строка: год · рейтинг (один знак) · длительность для фильма, для сериала —
количество обычных сезонов (сезон 0 не считается). Сезон по умолчанию — первый
регулярный; «Спецвыпуски» — чип с `seasonNumber === 0`, выбранный сезон уходит
в запрос раздач как `season`.

Жанры — не `Chip`, а такая же по виду `<span>`: `Chip` — это `<button>`, а жанр
не действие. Визуально не отличается.

Описание обрезается `line-clamp-4`, кнопка «Ещё» появляется только если
`scrollHeight > clientHeight` (измерение в `useLayoutEffect`, пересчёт на resize).
Тупиковой обрезки без раскрытия нет.

Ошибки: `TMDB_NOT_FOUND` — «Тайтл не найден» без повтора; `TMDB_NOT_CONFIGURED`
— отдельное сообщение без повтора; остальное — `ErrorState` с «Повторить».

### Экран раздач

`Sheet` из дизайн-системы без изменений: снизу на мобильном, по центру с
`max-width: 640px` на десктопе (у него уже `max-w-[640px]` и `items-end`).
Компонент монтируется только при открытии, поэтому запрос уходит по клику, а
состояние кнопок сбрасывается между открытиями. Закрытие — Escape, фон, крестик;
фокус возвращается на «Найти раздачи» (проверено в Chrome).

Фильтры клиентские, поверх одного ответа Prowlarr (`limit=150`):

- разрешение: все / 2160p / 1080p / 720p / ниже (480p, 576p);
- минимум сидов: любые / 5+ / 20+;
- трекер: селект из уникальных `indexer`;
- «Без CAM/TS» — исключает `CAM`, `TS` и `TC` (TC — тот же camrip, в названии
  фильтра он не упомянут);
- сортировка: сиды / размер / дата по убыванию, по умолчанию сиды; при равенстве
  добиваем по сидам.

Счётчик в заголовке — количество после фильтров: `Раздачи · 8`. Предупреждения
`warnings` — компактная жёлтая плашка «Часть индексаторов недоступна» (какие
именно — не перечисляем, чтобы не раздувать подвал).

`В Transmission` — отдельная мутация на карточку (`useAddTorrent` внутри
`ReleaseCard`), поэтому состояния независимы. `idle → loading → added |
duplicate | error`; ошибка показывает `message` сервера и «Повторить», у раздачи
с 0 сидов кнопка disabled с подписью «Нет сидов» и красной точкой в подвале.
Успешное добавление инвалидирует кэш загрузок в `useAddTorrent`.

### Загрузки

`useTorrents` опрашивает раз в 5 с и не опрашивает в фоне. Коды Transmission:
0 — «Стоп» (warn), 1–2 — «Проверка» (warn), 3–4 — «Скачивание» (accent),
5–6 — «Раздача» (success). Сводка: число активных (не 100 % и не «Стоп») и
суммарная скорость. ETA показывается только для скачивания: у раздачи и паузы
он бессмысленен. Пусто — «Загрузок нет» + ссылка «Найти раздачу».
`TRANSMISSION_NOT_CONFIGURED` — отдельное сообщение без повтора.

### Токен доступа

`lib/token.ts` — единственное место, где живёт `filmfind.token`; `api/client.ts`
читает его на каждый запрос. Любой ответ 401 (не только `code: 'UNAUTHORIZED'`)
включает состояние «нужен токен»; `TokenDialog` подписан на него через
`useSyncExternalStore` и появляется только после реального отказа — без
`APP_ACCESS_TOKEN` окна нет.

Диалог нельзя закрыть: пока сервер закрыт, остальные экраны всё равно получат
401. Tab зациклен, автофокус в поле, `aria-modal`, блокировка скролла. После
«Войти» токен пишется в storage, состояние снимается, `invalidateQueries()`
перезапускает активные запросы уже с заголовком. Неверный токен → снова 401 →
диалог возвращается.

Иконка выхода в шапке видна только при сохранённом токене: чистит storage и
инвалидирует кэш; если сервер закрыт, сразу появляется диалог.

### Картинки при включённом токене

Серверный хук авторизации закрывает весь `/api/*`, включая `/api/img/*`, а
`<img src>` не умеет отправлять `Authorization`. Поэтому `useAuthedImage` при
сохранённом токене скачивает картинку через `fetch` с заголовком и подменяет
адрес на blob URL (старые URL отзываются). Без токена возвращается обычный
`/api/img/...` — лишних запросов нет. Проверено на моке с `MOCK_TOKEN`: постер и
backdrop грузятся (`naturalWidth > 0`), а не показывают заглушку.

### Навигация и шапка

`goBack()` хранит глубину в `history.state`: после перехода из поиска «Назад»
возвращает на `/?q=…` с сохранённым запросом, а прямая ссылка на карточку уводит
на `/` (не в чужую историю браузера).

Шапка одна на всех экранах кроме стайлгайда. На карточке она прозрачная поверх
backdrop и добавляет кнопку «Назад» (44 px). Ссылки — 44 px, `aria-current` на
текущем разделе. `StatusDot` на узких экранах показывает только точку (подпись
`N/3` — с `sm`), чтобы шапка не расползалась.

### Доступность

- `aria-live="polite"` для выдачи поиска, количества раздач и сводки загрузок.
- Видимый фокус — глобальный `:focus-visible`, компоненты его не перебивают.
- Интерактив — нативные `button`/`a`/`input`/`select`, тач-таргеты ≥ 44 px
  (включая `size="sm"` кнопки, которым добавлен `min-h-11`).
- `Sheet` и диалог токена держат фокус внутри и возвращают его наружу.
- Горизонтального скролла нет на 360 и 390 px (проверено), внутренние ряды
  чипов скроллятся отдельно.

### Цвета

Только токены Tailwind из `tokens.css`. В fallback-градиенте backdrop —
`var(--accent)`, `var(--surface-2)`, `var(--surface)`, `var(--bg)` через
`color-mix`, без hex-литералов.

## Проверка

```bash
npm run build                       # shared + server + web (tsc --noEmit, vite build)
npm test                            # 149 серверных + 121 shared
npm run typecheck -w @filmfind/web
```

Мок-сервер и CDP-сценарии лежали в `/tmp` (`filmfind-mock/`), в репозиторий не
попали. Мок умел: `MOCK_TOKEN=secret` (401 на весь `/api/*`, кроме `/api/health`),
`MOCK_PROWLARR=missing` (503), `MOCK_EMPTY=1` (пустые раздачи и загрузки).

Проверено в headless Chrome (390×844, 360×800, 1280×900), без ошибок в консоли:

1. Поиск → «Дюна» → карточка: заголовок документа, мета, жанры, «Ещё»/«Свернуть».
2. «Найти раздачи» → Sheet: 8 карточек, счётчик, плашка warnings.
3. «В Transmission»: «Добавлено», «Уже есть» (duplicate), ошибка 502 с текстом
   сервера и «Повторить», «Нет сидов» disabled у раздачи с 0 сидов.
4. Фильтр «Без CAM/TS»: 8 → 7 карточек; Escape закрывает Sheet и возвращает фокус.
5. `/downloads`: сводка, три статуса, проценты, скорость, ETA; после добавления
   раздачи список обновился.
6. Сериал: сезоны «Спецвыпуски / Сезон 1…», пустая выдача для сезона 0.
7. 404: «Тайтл не найден» без повтора; Prowlarr/Transmission не настроены.
8. Токен: 401 → диалог, неверный токен → диалог снова, верный → данные и
   иконка выхода, выход → снова 401.
9. `/styleguide` не изменился.
10. Ширина страницы равна viewport на всех экранах (нет горизонтального скролла).

## Что осталось на полировку

- Блок фильтров в Sheet занимает ~300 px на телефоне: видно полторы карточки.
  Можно свернуть фильтры в одну строку или спрятать под «Фильтры (2)».
- `warnings` не перечисляет, какие индексаторы упали: сервер отдаёт строки, можно
  выводить их в раскрывашке.
- Blob-картинки не кэшируются между экранами: при возврате постер скачивается
  заново (серверный кэш изображений при этом работает).
- На экране загрузок нет действий (пауза/удаление/приоритет) — в задаче их не
  было, но экран к этому готов.
- Дубликат и «Добавлено» живут до закрытия Sheet; после переоткрытия состояние
  сбрасывается, хотя раздача уже в Transmission. Можно сверять по `infoHash`
  со списком загрузок.
- Заголовок вкладки на 404 — «Тайтл не найден — FilmFind», на ошибке загрузки —
  просто «FilmFind»; можно уточнить.
